Mixer configuration

Same options as LV1's session config. Strip banks are fixed — rename, reorder or reset strips; none can be added or deleted. Only named strips are built into the session.

Inputs

Patch = the input on the PATCH tab: new inputs take the device inputs top-down (Auto, stereo takes two) until you patch them there. DS on a row adds a digital split — the same input on another strip, off the master, for monitors (.emo only: never on the PDF, sheet or stage). Group, Link, Mute and Matrix are assigned on PATCH › INTERNAL (MULTI = several): click one to open the input's row there. Click a row's # to select (Shift = range, Ctrl = add/remove, Esc = clear) · drag the # to move rows.

Patch

The show's SoundGrid I/O devices, in LV1 slot order (A1–A8, then B1–B8): add them below; in the patch window's top strip drag a device's ⋮⋮ to reorder it and ✕ removes it. The patch window works like LV1's: pick a view (INPUT / OUTPUT / INTERNAL / DEVICE TO DEVICE), the devices to show (top strip) and click or drag across cells (drag straight or diagonally to patch a run). INTERNAL assigns strips to any number of groups, Main, matrixes, links and mute groups (LV1's rules: grey cells are not possible) — the only place to assign groups, matrixes, links and mutes: the INPUTS / OUTPUTS tables show them read-only (MULTI for several) and a click there opens the strip's row here. New inputs patch themselves top-down (Auto) through the Mic/Line and MADI inputs until you patch them here. In the Input views each preamp has its Gain knob (drag up/down, wheel, arrow keys; double-click = +20 dB) and 48V button above its column. All of it goes into the .emo session.

Custom layers

LV1's 8 custom layers (main Overview screen) — 16 strips each, any strip type, each strip once per layer. Click a strip below to add / remove it · drag it onto a slot to place it · drag slots to reorder · drag a layer tab (⋮⋮) to reorder the layers.

Show notes

Travel with the show: printed on the vendor PDF and written to the Google Sheet, right under the show name / date / venue.

Export .emo builds the complete LV1 session right in the browser, on the factory template of the selected mixer configuration (the show name becomes the file name) — each input row is that LV1 channel: an empty row between named inputs is a placeholder, built as an empty default strip that still takes its input; empty rows after the last named input aren't built. Import .emo… loads any LV1 session back into the builder (patch, mic/stand/position and notes are not stored in .emo and start empty). The vendor PDF carries the input list (#, name, format, mic, stand, stage position for named inputs — no routing or racks) plus the stage plot as a landscape page. Patch holds the show's SoundGrid I/O (MGB, Waves Classic, IONIC 16 / 24, DSPRO SG1000 / SG4000; up to 16 devices, in LV1 slot order) and LV1's patch window: Input A / B, Output Direct / Mix Busses and Device to Device, with each preamp's Gain and 48V above its column. New inputs patch themselves top-down (Auto) until you patch them there. The .emo session gets every device pre-assigned offline and the whole patch; importing an .emo reads it back. Export DiGiCo SD10 (beta) writes the inputs only — names, mono/stereo, port N on Rack 1 Mic N and the Insert A send on MADI N (the MADI port is renamed “LV1”), row for row like the .emo (a placeholder is “Ch N”, patched), digital splits left out. It edits your own SD10 default session: the first export asks for it (SD10 offline editor: new session, Save As) and keeps it in this browser; Shift-click to pick another. Open the result in the SD10 offline editor and Save As before it goes near a console. Racks: each strip's rack is 8 slots (1–8), exactly like LV1. The default EMO-F2 / EMO-D5 / EMO-Q4 are ordinary rack plugins — delete, reorder (drag or ↑↓) or re-add them like anything else. The searchable picker lists only SoundGrid-compatible plugins (those shipping SoundGrid-server process code) scanned off this machine's Plug-Ins V16/V17 bundles — the same set LV1's own menus show. Plugins load with their factory default preset. “Stock” racks (F2 → D5 → Q4) export no rack field.
